# Subtitle evaluation

The scoring module reads rendered SRTs. Production generation must never load this directory. The nine cases and source hashes are in `references.json`. Keep audio, subtitles, logs and listener overlays under ignored `gitignored-inputs/evaluation/`. The tracked legacy files contain measurements and provenance.

## Independent timing evidence

IngCrowd's *Japanese Themed Casual Conversation Corpus*, dialogue 01, supplies manually segmented utterances, transcriptions and recording-local speaker IDs. The test uses every complete ELAN annotation in the **first 23 seconds** of the mixed recording, from the start of the file through sample 367999 at 16 kHz. The source labels provide their own edge positions. Boundary uncertainty is unreported. Only the mixed audio is an automatic input. This is a noncommercial research evaluation under CC BY-NC 4.0. The frozen reference manifest reproduces the selected ELAN text and times with the speaker tiers and annotation IDs. [IngCrowd corpus and license](https://huggingface.co/datasets/IngCrowd/japanese-themed-dialogue/tree/e2eed8769400269f20821deb0e47e68b40012e8b) · [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/)

Obtain `japanese-themed-dialogue01_audio.wav` and `japanese-themed-dialogue01.eaf` in the dialogue 01 directory at that revision. Their SHA-256 digests are respectively `ea1138f2b05e6b3cc9580ed1196748ed67c5847f222c1cf4a54de6bf4d9d3282` and `c59daa71d0ffa34e50b4c532d33f5c0d2a51ceaa8aea4435a68a87d924f61b32`. The fixture WAV uses Python's `wave` writer with the source parameters and the first 368000 native frames. A local copy lives at the path in the manifest. Gaps, false dialogue and chorus abstention on the project clips are separate listening checks. [Project research](../docs/whisper-input-findings.md#acceptance-cases-for-the-build)

## Matching rules

- IDs are scoped to their recording. The search window is an exchange locator, inclusive of any cue intersecting it. It supplies no timing reference. Match the first available occurrence of a listed surface in reference order within that speaker's exchange. Ignore punctuation, whitespace, case and Unicode width. Multiple phrases in one cue share its exported times. A character can supply only one occurrence. The same continuing line across touching states counts once. A split phrase can span touching states of the same owner.
- For rebuilt ownership, remove the writer's generated label and attach its recording-local voice ID to each displayed line using bundle evidence. Fit one injective voice-to-reference map to all recovered, independently owned phrases in that recording. Maximize the number of matches, breaking ties by sorted IDs. Score unknown owners as unresolved. Review recurring voice equivalence separately from lexical recovery where spelling is uncertain. Legacy ownership and detector metrics are unavailable.
- For overlap, require positive intersection and at most 500 ms absolute error on **both** edges. Maximize chronological one-to-one matches, then minimize total absolute edge error, then choose earliest index pairs. The natural interruption has approximate listener evidence and an observed detector output. Only controls with exact reference events enter this quantitative gate.
- Use the fixed baseline-recovered set for coverage and its independently annotated subset for timing. Report signed edge errors, matched and missing IDs, and paired median absolute errors. Replacing a lost phrase with a new one fails coverage. A missing timed phrase or an empty timing set fails timing. To pass the paired gate one median must improve and the other may stay equal or improve.

## Reproducing the baseline

Use the legacy package at `5bf2697` and the tool and checkpoint identities recorded in `legacy-run.json`. Verify the five video hashes against both local feasibility records (`manifest.json` and `inputs.sha256`). Verify all remaining input hashes in `references.json`. Place symlinks to each input in an empty ignored evaluation directory. Run the original `yomisub.generation.generate_subtitles` with the four adapters wired in the legacy launcher and pass each symlink as the video path, the listed audio ordinal, language `ja`, and model `medium`. This writes the final SRT beside the symlink. The controls and timing fixture have untagged WAV streams with known Japanese speech. Effective Vulkan device selection is recorded in the actual stderr logs.

From the project root, run `uv run --locked python -m evaluation.score gitignored-inputs/evaluation/legacy` and compare its JSON to `legacy-scores.json`. Per-scene results and recovered IDs are frozen there. Across the nine recordings, four of nine independent timing utterances matched. The respective legacy medians are 1815 ms for onset and 1305 ms for release.
