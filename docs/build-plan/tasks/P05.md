# P05 — Prepare the selected track and preserve its clock

**Size:** 8. **Prerequisite:** P04.

## Work

- Use stream metadata and actual decoded sample counts to describe the selected audio relative to video playback. Record global stream index, audio ordinal, channel layout, start, rate and frame count. Verify extraction maps the chosen track even when global index and ordinal differ.
- Retain the selected track with its original channels for replay. Produce a 16 kHz mono source for both ASR and diarization. Reconcile any start offset, trim, discontinuity or added silence with the playback clock. Report a timing mapping failure when the relation cannot be established.
- Implement sample-based crops and exact rate conversion. Restrict emitted ranges to available audio while retaining the requested range and actual source mapping for review.

## Acceptance

- Test a nonzero media start, delayed audio, two distinguishable audio streams, exact 8-to-16 kHz mapping and a crop crossing the recording end. Generate or use a real multitrack fixture and verify selected stream content and mapped playback times with FFmpeg tooling.

- Use a 44.1 kHz source and a 16 kHz analysis crop whose start falls between source samples. Calculate the rational playback time independently. Round the extraction start down and end up to whole samples, clip at source bounds and record what was actually read. Verify adding the stream-to-playback offset exactly once.

- In the numeric fixture the video starts at PTS 10 s and the 44,100 Hz track starts at PTS 10.25 s. Analysis sample 1 at 16 kHz maps to recording sample 441/160 and playback time 4001/16000 s. The crop [1, 2) on the analysis clock covers [2, 6) on the native sample grid after outward rounding. Check early audio that falls before playback zero is retained as evidence and excluded from the pre-zero display interval.
