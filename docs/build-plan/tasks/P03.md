# P03 — Resolve compute per model stage

**Size:** 5. **Prerequisite:** P02.

## Work

- Register providers by supported model operation and enumerate eligible physical devices. Resolve a stable PCI address or UUID into a runtime-local binding. Keep runtime indices, device visibility, and process environment handling in providers.
- Read `$XDG_CONFIG_HOME/yomisub/compute.toml`, falling back to `~/.config/yomisub/compute.toml`. Document stage keys for baseline ASR, retry ASR, diarization, separation and stem ASR. Resolve an explicit stage setting first, then a compatible configured default, then the sole compatible device. On ambiguous or invalid selection, report the stage and available compatible choices.
- Keep the registry extensible through provider registration. The application owns stage order and the selected provider owns effective-device verification.

## Acceptance

- Assign two stages to distinct fake GPUs. Reorder same-name devices across runtimes and verify their physical identities still control placement. Cover invalid, hidden, incompatible and ambiguous device selection. Register a second fake provider through the same interface without editing the use case.

## Sources

- The experiments used Vulkan for Whisper and ROCm for speaker models on one Radeon. Per-stage selection and future NVIDIA provider support are design requirements. The experiments did not establish cross-GPU performance.
