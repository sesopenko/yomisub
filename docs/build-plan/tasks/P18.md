# P18 — Publish the three artifacts recoverably

**Size:** 5. **Prerequisite:** P17.

## Work

- Finish and validate SRT, ASS and the evidence ZIP in destination-local staging. Publish using the planned sibling filenames. Serialize concurrent publications for the same stem and language.
- Before replacement, retain the prior complete outputs and record enough transaction state to recover an interrupted replacement. On retry, recover under the same lock before staging another generation. Report the three paths only once they belong to one complete run.

## Acceptance

- Inject failure at every replacement, including an initial publication with no prior files. Simulate process interruption and verify a subsequent run recovers the previous complete set. Run two competing publications and verify the final three files come from one run.
