# P01 — Define domain values

**Size:** 5. **Prerequisite:** P00.

## Work

- Define immutable values for the recording clock, selected stream, half-open sample ranges, and source mappings. Each derived source has an identity, parent, rate, origin, padding and delay. Preserve the relationship to video playback time. Keep file paths and runtime handles in adapters.
- Define separate values for raw observations and validated timing. Store ASR run provenance, segment text, exact Unicode spans, and the original timing fields including units and rejected values. Keep raw voice turns, attribution evidence, and estimated source columns independently addressable.
- Represent phrase hypotheses, optional listener decisions with provenance, planned phrases, active screen states, and review findings. A correction targets a stable evidence ID and can affect wording, ownership, or timing independently.

## Acceptance

- Construct a wordless voice turn, overlapping phrases with different owners, an excerpt-local stem without an assigned speaker, and a correction to one field. Verify each keeps its own identity.
- Store an inverted raw interval and an out-of-range raw end. Verify each remains inspectable and neither can be represented as a valid publishable interval. Check exact conversion at a nonzero source origin and across different sample rates.
