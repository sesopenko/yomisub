# P10 — Retry overlaps on the contextual original mix

**Size:** 5. **Prerequisite:** P09.

## Work

- Start with continuous ASR intact. Generate a large-v3 original-mix crop for each detected overlap core, with up to two seconds of real audio on either side. Clamp the context to source bounds. Keep the core and context independently addressable.
- Give each retry its own input, model run and original-clock mapping. If contexts intersect, retain each event’s core and link it only to the retry that covered it. Keep candidates from context available as observations and leave nearby dialogue in the baseline.
- Preserve failed retry details with the event. Pass alternatives to reconciliation and let P13 and P14 decide which evidence supports a line.

## Acceptance

- Test overlaps near each edge, intersecting windows, no-overlap input and unsuccessful retries. Verify the padded window cannot expand detected coactivity or replace nearby continuous speech.
- Add a regression for the two S01E10 crop outcomes. The 24–29 s mix and the 24.221–28.744 s mix gave different candidate text. Verify each result retains its own origin and wording.

## Sources

- Cutting the baseline at overlaps lost dialogue. The contextual mix is the recommended retry and its result remains sensitive to crop boundaries.
