# P21 — Verify accuracy and hardware on real media

**Size:** 8. **Prerequisite:** P20.

## Work

- Run the new automatic pipeline and the P04 frozen legacy baseline on the same selected streams, models and comparable inputs. Keep references out of both automatic runs. Score matched phrases, misses, ownership, onset error, release error and waveform overlap detection separately. Run a second pass with explicit listener corrections for the replay comparison.
- Exercise all research cases below. Record the input and track identity, model and runtime provenance, output or evidence locations, and per-scene measurements. Annotate phrase timing from separately listened speech, including solo sources for the controls. Leave disputed natural timings unscored.
- Through GTK, generate all three outputs for a short language-tagged multitrack video using `tiny`, then replay its bundle offline. Record AMD Vulkan and ROCm devices, stage wall times and peak memory where measured. Exercise two physical GPUs when available and label simulated placement as such. Report clip measurements in their measured scope.

| S01E01 ordinary dialogue | Verify recurring voice, distinct speakers in the checked exchange, the brief aside, and the unresolved spelling. |
| S01E03 fight | Score `こうします／そう／たえられる` against A/B/B. Preserve the previously observed merged-ID case as a regression and verify corrections work on replay. |

## Acceptance

- On the same matched phrases, achieve lower median absolute error for onset or release with the other median no worse, plus preservation of verified baseline phrase coverage. Include the size of the matched set and the misses.
- Verify correct automatic attribution on a checked exchange, detection of a reference-backed overlap, and correct display of overlapping phrases with supported wording, ownership and timing. Report the source of that display evidence and record automatic and corrected scores separately.
- Rerun the standard gates and add a regression for every defect resolved here. If a gate fails, leave it open and follow the plan’s correction and sizing rules.
