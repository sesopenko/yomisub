# P09 — Scan the full track and measure speaker activity

**Size:** 5. **Prerequisite:** P08.

## Work

- Run pyannote speaker-diarization-3.1 on the same continuous mono source as the baseline ASR. Use the binding from preflight. Preserve each diarization run’s identity, raw turns and recording-local speaker IDs.
- Parse RTTM onset and duration on the recording clock. Sweep half-open intervals to measure union coverage per voice, coactive time, and uncovered time within a candidate range. Repeated or nested detections for an ID count as one active voice. Keep multi-voice events even when ASR found no words.
- Represent a successful empty scan as valid evidence. Route worker failure or malformed output to the required-stage error path. Coverage describes activity and remains separate from phrase ownership.

## Acceptance

- Run the scanner contract with adjacent and nested turns, repeated IDs, empty results and a crash. Reproduce a recorded coactivity interval from RTTM and verify that changing the clock origin keeps the duration and moves both edges together.
