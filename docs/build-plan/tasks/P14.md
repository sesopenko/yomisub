# P14 — Spot phrase onsets, releases and timed cuts

**Size:** 8. **Prerequisite:** P13.

## Work

- Validate piece and segment timing against their own run, source, and recording bounds. Retain invalid raw values and validation reasons. Estimate onset and release independently. Use adjacent whole-piece edges for internal cuts only when their intervals are positive, ordered and within bounds and the language strategy permits the break.
- Use a wider supported phrase when the internal anchors fail. Send candidates with unsupported edges for review. Preserve the detected overlap as activity evidence even if the two phrases have unreliable endpoints.
- Recompute per-voice coverage on the final interval. A solo assignment requires exclusive coverage throughout. On expansion into coactivity, retain an owner only if that phrase meets P13’s timed solo-continuation rule or has explicit listener support. Clear the automatic owner when narrowing removes its supporting lexical portion. Test both expansion and contraction. Admit a disputed second line to layout only with supported wording, ownership and both edges.
- Keep short replies and meaningful pauses where supported. Measure reading demand separately. Remove the legacy fixed tail and cap from the new path.

## Acceptance

- Check early entry, late release, a long phrase, a brief reply, silence, late negation, backwards timing, and media-end overrun. Verify cue timing is independent of cue length and cannot create a growing delay. Include the S01E03 inverted piece and a natural overlap whose voice activity edges cannot become phrase timestamps.

- For each outer edge, prefer an in-bounds listener timing decision, then a valid outer lexical edge from that phrase’s own decode. Fall back to the enclosing valid segment for the whole unsplit phrase. If combining selected edges yields an invalid interval, retain it for review. Test independent choices for start and end and a valid internal cut that produces two ordered phrases.
