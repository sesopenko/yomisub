# P06 — Bind Whisper to an AMD Vulkan device

**Size:** 5. **Prerequisite:** P05.

## Work

- Implement the Vulkan provider behind the compute contract. Discover AMD devices by physical identity, map them to the active Whisper runtime’s device order, and respect inherited visibility restrictions. Check the executable’s supported flags and runtime device reporting against the installed build.
- Pass selection only to the inference child. Parse or otherwise verify the effective GPU and surface mismatches, unavailable devices and CPU fallback as actionable setup errors.

## Acceptance

- Run the provider contract with shuffled indices, equal names, hidden devices, and a child reporting a different backend. Run the tiny-model smoke test on the Radeon and record the selected physical device, reported backend, model and command.
