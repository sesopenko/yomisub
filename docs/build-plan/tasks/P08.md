# P08 — Provision and probe the ROCm worker

**Size:** 5. **Prerequisite:** P07.

## Work

- Package a separate Python 3.12 worker for the researched ROCm stack and leave GTK on Python 3.13. Freeze the worker’s dependencies and document its interpreter, model cache paths and gated model setup.
- Implement a versioned subprocess protocol with capability discovery and preflight for the required diarizer. Report visible device identities, verify selected ROCm execution, and distinguish missing interpreter, unavailable device, incompatible runtime and inaccessible weights. Keep optional SepFormer capability independently checkable.
- Keep protocol responses machine-readable and redact credentials from diagnostics, commands and bundles. Use the tested model versions and record the effective runtime and device.

## Acceptance

- Mock missing interpreter, unsupported protocol version, inaccessible weights and wrong device. Verify each error names the recovery step and excludes secrets. Run a live capability probe against the pinned Radeon stack and record the effective versions and device.

- Probe required scan capability separately from optional separation. Check the selected physical ID against the effective child device after visibility filtering. Test that a missing optional checkpoint leaves an otherwise usable scanner available.

- Provision a fresh worker environment from the project instructions, reusing cached wheels and authorized model weights where available. Verify the packaged probe there, with only the required diarizer weights available. Keep unrelated research model caches out of its prerequisites.

## Sources

- The measured environment used Python 3.12, ROCm 6.4.2, PyTorch 2.6.0 and pyannote.audio 3.3.2. Validate the packaged worker against that known environment.
