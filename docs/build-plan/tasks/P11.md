# P11 — Add optional SepFormer listening and stem ASR

**Size:** 5. **Prerequisite:** P10.

## Work

- Enable the optional path only when requested. Run the tested two-source 8 kHz SepFormer WHAMR checkpoint for exactly two active IDs and cores at most 12 seconds long, with up to two seconds of real context on each side. Record skipped or failed refinements as review findings with the core intact.
- Retain both estimated waveforms in their native rate, recording source column, crop origin, padding, delay and parent mix. Convert them to 16 kHz for optional large-v3 ASR without losing their source mappings. Keep stem indices local to the excerpt.
- Preserve the original mix and all competing hypotheses. Leave uncertain assignments open. Keep experimental embedding thresholds and clean control references out of production attribution.

## Acceptance

- Check two stem mappings through resampling, a delayed stem, swapped columns in adjacent excerpts, an absent stem, a three-voice core and an overlong core. Confirm unsupported cases keep the original mix and candidate text and report the omitted refinement.

- Enable separation through the P02 headless request flag and attempt large-v3 on each available stem. P20 exposes the same flag in GTK. Keep usable audio when a stem decode fails and identify the failed operation. Run the adapter on one bounded research core on the Radeon. Record both native-rate stem lengths, mapped origins, ASR runs, checkpoint identity and effective device. Assess waveform mapping and evidence retention independently of transcript quality.
