# P17 — Save an evidence bundle and replay it offline

**Size:** 8. **Prerequisite:** P16.

## Work

- Define a versioned ZIP manifest with relative member names and stable references. Store the recording clock, original-channel listening audio, available stems, raw observations, validated mappings, run provenance, editorial decisions and review reasons. Retain the distinction between an observed candidate and the final decision.
- Implement a headless replay command and document its input, output directory and optional corrections file. Apply explicit corrections by evidence ID, with provenance, and reuse the generation planner and writers. Make required planning data available offline, including any language analysis needed to reproduce the original cues.
- Replay produces two subtitle files in the requested output directory. Refuse existing destination filenames before writing either file. This works for relocated bundles and preserves original generation files. Validate supported schema and planner versions, required members and cross-references. Report missing, damaged or unsupported evidence with the path and recovery action.

- Save segmentation spans, proposed cuts and format-specific diagnostics with stable IDs. A corrections file identifies its source bundle and supports field-level edits, suppressing an unsupported phrase, and adding a listener-supported phrase on a recorded interval. Use half-open sample indices on the manifest’s recording clock. Require listener provenance and accept interval notes such as verified silence or unresolved vocals.
- A replacement surface invalidates the old text offsets. Preserve those offsets with the original reading and replay the replacement as one phrase using its supported outer interval unless the listener supplies valid timed subdivisions. Test a length-changing edit offline. Validate the entire corrections file before touching either output. For unknown IDs, conflicting edits, or invalid spans, verify pre-existing output bytes survive.

## Acceptance

- Relocate the bundle and recreate byte-identical SRT and ASS with inference disabled. Change one phrase via a corrections file and trace the changed cue back to its evidence. Test a damaged archive, unsupported version and broken source reference.

- Exercise a corrected timing edge and a listener-supported second line on a wordless turn. Check input bundle bytes before and after, the preserved automatic observations, and output when no tokenizer dictionary, private media or model runtime is available.
