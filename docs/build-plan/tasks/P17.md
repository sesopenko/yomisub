# P17 — Save an evidence bundle and replay it offline

**Size:** 8. **Prerequisite:** P16.

## Work

- Define a versioned ZIP manifest with relative member names and stable references. Store the recording clock, original-channel listening audio, available stems, raw observations, validated mappings, run provenance, editorial decisions and review reasons. Retain the distinction between an observed candidate and the final decision.
- Implement a headless replay command and document its input, output directory and optional corrections file. Apply explicit corrections by evidence ID, with provenance, and reuse the generation planner and writers. Make required planning data available offline, including any language analysis needed to reproduce the original cues.
- Validate manifest version, required data and cross-references. Report missing, damaged or unsupported evidence with the path and recovery action.

## Acceptance

- Relocate the bundle and recreate byte-identical SRT and ASS with inference disabled. Change one phrase via a corrections file and trace the changed cue back to its evidence. Test a damaged archive, unsupported version and broken source reference.
