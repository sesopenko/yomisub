# P19 — Compose the production generation workflow

**Size:** 5. **Prerequisite:** P18.

## Work

- Build the production factory that constructs adapters through the application contracts. Preflight required model operations, their selected devices and the speaker runtime before decoding media or loading ASR. Run model stages sequentially, each with its own effective device.
- Prepare the selected track, run continuous ASR and independent diarization, and gather contextual retries and optional stem evidence. Run the shared planner, stage the three artifacts and publish only after required stages succeed.
- Report stage progress and manage temporary resources from the application boundary. Keep optional-stage failures in the result and bundle while retaining the continuous evidence. Include stage durations and effective device provenance for acceptance.

- Compose the actual generation workflow exercised by P02’s fakes. Expose it to integration tests through a production factory. Keep the existing GTK launcher working with its legacy result until the P20 switch. Bind optional model operations only when needed and capture writer diagnostics before sealing the bundle.

## Acceptance

- Through the production entry point with controlled adapters, exercise normal generation, a required preflight failure, a scan crash after preflight, an optional retry failure, and a repeat run. Verify resource cleanup and publisher behavior. Exercise single-device and split-device selection through the same entry point.
