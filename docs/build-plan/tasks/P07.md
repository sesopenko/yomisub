# P07 — Capture continuous Whisper observations

**Size:** 5. **Prerequisite:** P06.

## Work

- Replace the raw SRT handoff with full JSON from `whisper-cli` using `-ojf`. Send the uninterrupted 16 kHz original mix to the selected multilingual model. Keep medium as the default. Resolve full large-v3 separately for retries. Record build, options, checkpoint hash, source, language and effective device.
- Preserve raw segment text, token IDs, offsets, lexical probabilities and optional timing fields. Exclude control tokens from the text join using the build’s vocabulary. Keep decoder byte assembly and leading spaces intact. Treat mismatched reconstruction as degraded piece evidence while retaining segment text.
- Keep optional DTW points attached to their own decode with explicit units and availability. A point or token probability cannot serve as an interval or speaker confidence.

- Introduce the JSON adapter alongside the legacy SRT generation path. Keep existing callers working through the P20 switch. Checkpoint verification for the retry must identify the full large-v3 weights against the digest in the separation report.

## Acceptance

- Parse full-JSON fixtures with multicharacter Japanese pieces, whitespace, controls, invalid and missing offsets, and DTW sentinels. Verify a point from an alternate decode cannot attach to the baseline run. Test model resolution and assert one continuous source reaches the baseline adapter.

- Resolve the CLI from the documented PATH setup and models through the existing first-use cache. Test a cache hit and a missing or truncated download so an incomplete file cannot become the recorded checkpoint.
