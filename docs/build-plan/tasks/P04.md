# P04 — Freeze the legacy baseline and score offline

**Size:** 5. **Prerequisite:** P03.

## Work

- Capture the legacy output before replacing its generation path. Record the revision, selected stream, input hash, model and checkpoint, recognizer build, effective backend, and invocation. Keep the baseline outputs and run manifest in a reproducible evaluation location.
- Build a compact offline fixture for scorer tests and a separate manifest for the local research media. Record per-case phrase references, speaker equivalences, verified silence, uncertain words or boundaries, and waveform overlap references only where the source specifies them. Keep listener references and clean control sources out of the automatic inputs. Use separate annotations of audible speech for phrase timing.
- Score phrase recovery and omission, wrong or unresolved attribution, overlap detection, and onset and release errors independently. Match each prediction to at most one reference. Compare anonymous IDs through recording-local correspondences, retaining label conflicts and abstentions. Document the matching rule before evaluating the new workflow.

## Acceptance

- Unit-test the scorer with a missing phrase, a wrong owner, an abstention, an overlap false positive, and a correct onset with late release. Report matched timing counts and explicit unknowns. Run and record the legacy scores before production generation changes. Fixture tests run without private media.
